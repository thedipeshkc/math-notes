# Algebra & Pre-Calculus Notes

A math reference site built with plain HTML, CSS, and MathJax.

I'm a CS major at Morehead State University, working as an embedded tutor
with Prof. Caleb Hinds and as a math tutor/proctor in the Math Lab. This
site came out of that work — a place to put together clean notes and
practice problems for algebra and pre-calculus students.

Still a work in progress. More chapters and problems will be added over time.

## What's here

- Algebra: Exponents, Polynomials, Factoring, Solving Equations, Exponentials & Logs
- Pre-Calculus: Trig Basics, Trig Identities
- Cheat sheets and common error guides
