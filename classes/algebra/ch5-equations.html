Chapter 5: Solving Equations

5.1 — Linear Equations

A linear equation in one variable has the form $ax + b = 0$. The solution is simply $x = -b/a$ (when $a \neq 0$). The key principle: whatever you do to one side, do to the other.

Worked Example 5.1

Solve: $3(2x - 5) - 4 = 2(x + 1) + 6$

$$6x - 15 - 4 = 2x + 2 + 6 \implies 6x - 19 = 2x + 8 \implies 4x = 27 \implies x = \frac{27}{4}$$

5.2 — Quadratic Equations

A quadratic equation is $ax^2 + bx + c = 0$, $a \neq 0$. There are three main strategies:

Strategy 1 — Factoring
Factor the left side and apply the Zero Product Property: if $AB = 0$ then $A = 0$ or $B = 0$.
Strategy 2 — Completing the Square
Rewrite as $(x + p)^2 = q$, then take square roots: $x = -p \pm \sqrt{q}$.
Strategy 3 — Quadratic Formula
For $ax^2 + bx + c = 0$: $$x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}$$ The discriminant $\Delta = b^2 - 4ac$ tells you the number and type of solutions: $\Delta > 0$: two distinct real roots; $\Delta = 0$: one repeated real root; $\Delta < 0$: two complex roots.

Worked Example 5.2

Solve by completing the square: $2x^2 - 8x + 3 = 0$

$$x^2 - 4x + \tfrac{3}{2} = 0 \implies x^2 - 4x = -\tfrac{3}{2}$$ $$x^2 - 4x + 4 = -\tfrac{3}{2} + 4 = \tfrac{5}{2}$$ $$(x - 2)^2 = \tfrac{5}{2} \implies x = 2 \pm \sqrt{\tfrac{5}{2}} = 2 \pm \frac{\sqrt{10}}{2}$$

5.3 — Equations Involving Radicals

Isolate the radical, then raise both sides to the appropriate power. Always check your answers — squaring both sides can introduce extraneous solutions.

Worked Example 5.3

Solve: $\sqrt{3x+4} - \sqrt{x} = 2$

Isolate one radical: $\sqrt{3x+4} = \sqrt{x} + 2$. Square both sides:

$$3x + 4 = x + 4\sqrt{x} + 4 \implies 2x = 4\sqrt{x} \implies x = 2\sqrt{x}$$

Square again: $x^2 = 4x \implies x(x-4)=0 \implies x=0$ or $x=4$.

Check $x=0$: $\sqrt{4}-\sqrt{0} = 2$ ✓. Check $x=4$: $\sqrt{16}-\sqrt{4}=2$ ✓. Both valid.

5.4 — Absolute Value Equations

Key Principle
$|X| = c$ (with $c \geq 0$) is equivalent to $X = c$ or $X = -c$.

Worked Example 5.4

Solve: $|2x - 5| = 9$

$$2x - 5 = 9 \implies x = 7 \qquad \text{or} \qquad 2x - 5 = -9 \implies x = -2$$

Practice Problems

Solutions:
Problem 1
Solve by factoring: $6x^2 - x - 15 = 0$
Solution

$ac = -90$. Need factors summing to $-1$: choose $9$ and $-10$.

$$6x^2 + 9x - 10x - 15 = 3x(2x+3) - 5(2x+3) = (3x-5)(2x+3) = 0$$ $$x = \frac{5}{3} \quad \text{or} \quad x = -\frac{3}{2}$$
Problem 2
Use the quadratic formula to solve: $3x^2 + 2x - 4 = 0$
Solution
$$\Delta = 4 + 48 = 52, \quad x = \frac{-2 \pm \sqrt{52}}{6} = \frac{-2 \pm 2\sqrt{13}}{6} = \frac{-1 \pm \sqrt{13}}{3}$$
Problem 3
Solve: $\sqrt{5x + 1} = x + 1$
Solution

Square both sides: $5x+1 = x^2+2x+1 \implies x^2-3x=0 \implies x(x-3)=0$.

$x=0$ or $x=3$. Check both in original: $x=0$: $1=1$ ✓. $x=3$: $4=4$ ✓.

Problem 4
Solve: $|3x + 2| = |x - 4|$
Solution

Case 1: $3x+2 = x-4 \implies 2x = -6 \implies x = -3$.

Case 2: $3x+2 = -(x-4) \implies 4x = 2 \implies x = \tfrac{1}{2}$.

Both solutions check out: $x = -3$ or $x = \tfrac{1}{2}$.
