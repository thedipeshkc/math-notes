Chapter 9: Exponentials & Logarithms

9.1 — Exponential Functions

Definition
An exponential function has the form $f(x) = a \cdot b^x$ where $b > 0$, $b \neq 1$, and $a \neq 0$.
If $b > 1$: the function grows. If $0 < b < 1$: the function decays. The most important base is $e \approx 2.71828\ldots$ (Euler's number), giving $f(x) = e^x$.

Key properties: domain is all reals $(-\infty,\infty)$; range is $(0,\infty)$; horizontal asymptote at $y=0$; always passes through $(0, a)$.

9.2 — Logarithms

Definition — Logarithm
$\log_b x = y$ means exactly $b^y = x$. In other words, the logarithm answers: "to what power must I raise $b$ to get $x$?"
Special cases: $\log_{10} x = \log x$ (common log), $\log_e x = \ln x$ (natural log).
Properties of Logarithms
$$\begin{align} \log_b(MN) &= \log_b M + \log_b N \\ \log_b\!\left(\tfrac{M}{N}\right) &= \log_b M - \log_b N \\ \log_b(M^p) &= p\log_b M \\ \log_b b &= 1 \\ \log_b 1 &= 0 \\ b^{\log_b x} &= x \quad \text{and} \quad \log_b(b^x) = x \end{align}$$ Change of base: $\log_b x = \dfrac{\ln x}{\ln b} = \dfrac{\log x}{\log b}$
Common Errors with Logarithms
$\log(M+N) \neq \log M + \log N$ and $\dfrac{\log M}{\log N} \neq \log\!\left(\dfrac{M}{N}\right)$. The log of a sum cannot be split.

9.3 — Solving Exponential and Log Equations

To solve exponential equations: isolate the exponential, take the log of both sides, apply the power rule.

To solve log equations: combine logs using properties, then convert to exponential form.

Worked Example 9.1

Solve: $5^{2x-1} = 13$

$$\ln(5^{2x-1}) = \ln 13 \implies (2x-1)\ln 5 = \ln 13 \implies x = \frac{\ln 13/\ln 5 + 1}{2} = \frac{\log_5 13 + 1}{2}$$

Worked Example 9.2

Solve: $\log_2(x+3) + \log_2(x-1) = 5$

$$\log_2[(x+3)(x-1)] = 5 \implies (x+3)(x-1) = 2^5 = 32$$ $$x^2 + 2x - 3 = 32 \implies x^2 + 2x - 35 = 0 \implies (x+7)(x-5) = 0$$

$x = 5$ or $x = -7$. Check: $x = -7$ gives $\log_2(-4)$ which is undefined. So $x = 5$ only.

Practice Problems

Solutions:
Problem 1
Evaluate without a calculator: $\log_3 \dfrac{1}{27}$
Solution
$$\log_3 \frac{1}{27} = \log_3 3^{-3} = -3$$
Problem 2
Expand using log properties: $\ln\!\left(\dfrac{x^3\sqrt{y}}{z^2}\right)$
Solution
$$= \ln x^3 + \ln y^{1/2} - \ln z^2 = 3\ln x + \tfrac{1}{2}\ln y - 2\ln z$$
Problem 3
Solve: $3^{x+2} = 7^{x-1}$
Solution
$$\ln 3^{x+2} = \ln 7^{x-1} \implies (x+2)\ln 3 = (x-1)\ln 7$$ $$x\ln 3 + 2\ln 3 = x\ln 7 - \ln 7 \implies x(\ln 3 - \ln 7) = -\ln 7 - 2\ln 3$$ $$x = \frac{-\ln 7 - 2\ln 3}{\ln 3 - \ln 7} = \frac{\ln 7 + 2\ln 3}{\ln 7 - \ln 3} = \frac{\ln 63}{\ln(7/3)}$$
Problem 4
Solve: $\log(x) + \log(x-3) = 1$
Solution
$$\log[x(x-3)] = 1 \implies x(x-3) = 10 \implies x^2 - 3x - 10 = 0 \implies (x-5)(x+2)=0$$

$x=5$ or $x=-2$. Since $\log(-2)$ is undefined, the only solution is $x = 5$.
