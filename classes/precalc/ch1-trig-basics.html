Chapter 1: Trigonometry Basics

1.1 — Angles and Radian Measure

Angles can be measured in degrees or radians. One full revolution is $360°$ or $2\pi$ radians.

Conversion Formulas
$$\text{radians} = \text{degrees} \times \frac{\pi}{180} \qquad \text{degrees} = \text{radians} \times \frac{180}{\pi}$$

Common angles to memorize:

Degrees$0°$$30°$$45°$$60°$$90°$$180°$$270°$$360°$
Radians$0$$\dfrac{\pi}{6}$$\dfrac{\pi}{4}$$\dfrac{\pi}{3}$$\dfrac{\pi}{2}$$\pi$$\dfrac{3\pi}{2}$$2\pi$

1.2 — The Six Trig Functions

Definition — Right Triangle
For an angle $\theta$ in a right triangle with opposite side $\text{opp}$, adjacent side $\text{adj}$, and hypotenuse $\text{hyp}$: $$\sin\theta = \frac{\text{opp}}{\text{hyp}}, \quad \cos\theta = \frac{\text{adj}}{\text{hyp}}, \quad \tan\theta = \frac{\text{opp}}{\text{adj}}$$ $$\csc\theta = \frac{1}{\sin\theta}, \quad \sec\theta = \frac{1}{\cos\theta}, \quad \cot\theta = \frac{1}{\tan\theta}$$
Definition — Unit Circle
For any angle $\theta$, place it in standard position on a unit circle. If the terminal side meets the circle at $(x, y)$, then: $$\cos\theta = x \qquad \sin\theta = y \qquad \tan\theta = \frac{y}{x} \; (x \neq 0)$$

Memory Trick — ASTC (All Students Take Calculus)
In each quadrant, which functions are positive? Q1: All; Q2: Sin (and csc); Q3: Tan (and cot); Q4: Cos (and sec).

1.4 — The Pythagorean Identity

Fundamental Identity
$$\sin^2\theta + \cos^2\theta = 1$$ Dividing by $\cos^2\theta$: $\tan^2\theta + 1 = \sec^2\theta$. Dividing by $\sin^2\theta$: $1 + \cot^2\theta = \csc^2\theta$.

Practice Problems

Solutions:
Problem 1
Convert $225°$ to radians and $\dfrac{7\pi}{4}$ to degrees.
Solution
$$225° \times \frac{\pi}{180} = \frac{225\pi}{180} = \frac{5\pi}{4} \text{ rad}$$ $$\frac{7\pi}{4} \times \frac{180}{\pi} = \frac{7 \times 180}{4} = 315°$$
Problem 2
Find the exact value of $\sin\!\left(\dfrac{5\pi}{6}\right)$ and $\cos\!\left(\dfrac{5\pi}{6}\right)$.
Solution

$\dfrac{5\pi}{6}$ is in Quadrant II. The reference angle is $\pi - \dfrac{5\pi}{6} = \dfrac{\pi}{6}$.

In Q2: sin is positive, cos is negative.

$$\sin\frac{5\pi}{6} = \sin\frac{\pi}{6} = \frac{1}{2}, \qquad \cos\frac{5\pi}{6} = -\cos\frac{\pi}{6} = -\frac{\sqrt{3}}{2}$$
Problem 3
If $\sin\theta = \dfrac{3}{5}$ and $\theta$ is in Quadrant II, find $\cos\theta$ and $\tan\theta$.
Solution

By the Pythagorean identity: $\cos^2\theta = 1 - \sin^2\theta = 1 - \dfrac{9}{25} = \dfrac{16}{25}$.

In Q2, $\cos\theta < 0$, so $\cos\theta = -\dfrac{4}{5}$.

$$\tan\theta = \frac{\sin\theta}{\cos\theta} = \frac{3/5}{-4/5} = -\frac{3}{4}$$
Problem 4
Find all $\theta \in [0, 2\pi)$ satisfying $\cos\theta = -\dfrac{\sqrt{2}}{2}$.
Solution

Reference angle: $\cos^{-1}\!\left(\dfrac{\sqrt{2}}{2}\right) = \dfrac{\pi}{4}$.

Cosine is negative in Q2 and Q3:

$$\theta = \pi - \frac{\pi}{4} = \frac{3\pi}{4} \quad \text{and} \quad \theta = \pi + \frac{\pi}{4} = \frac{5\pi}{4}$$
