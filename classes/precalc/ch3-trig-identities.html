Chapter 3: Trigonometric Identities

3.1 — Fundamental Identities

Reciprocal & Quotient Identities
$$\csc\theta = \frac{1}{\sin\theta}, \quad \sec\theta = \frac{1}{\cos\theta}, \quad \cot\theta = \frac{1}{\tan\theta}$$ $$\tan\theta = \frac{\sin\theta}{\cos\theta}, \quad \cot\theta = \frac{\cos\theta}{\sin\theta}$$
Pythagorean Identities
$$\sin^2\theta + \cos^2\theta = 1 \qquad \tan^2\theta + 1 = \sec^2\theta \qquad 1 + \cot^2\theta = \csc^2\theta$$
Even/Odd Identities
$$\sin(-\theta) = -\sin\theta \quad \text{(odd)}, \qquad \cos(-\theta) = \cos\theta \quad \text{(even)}$$ $$\tan(-\theta) = -\tan\theta \quad \text{(odd)}$$

3.2 — Sum and Difference Formulas

Sum & Difference
$$\sin(\alpha \pm \beta) = \sin\alpha\cos\beta \pm \cos\alpha\sin\beta$$ $$\cos(\alpha \pm \beta) = \cos\alpha\cos\beta \mp \sin\alpha\sin\beta$$ $$\tan(\alpha \pm \beta) = \frac{\tan\alpha \pm \tan\beta}{1 \mp \tan\alpha\tan\beta}$$

Worked Example 3.1

Find the exact value of $\cos 75°$.

$$\cos 75° = \cos(45°+30°) = \cos 45°\cos 30° - \sin 45°\sin 30°$$ $$= \frac{\sqrt{2}}{2}\cdot\frac{\sqrt{3}}{2} - \frac{\sqrt{2}}{2}\cdot\frac{1}{2} = \frac{\sqrt{6}-\sqrt{2}}{4}$$

3.3 — Double-Angle Formulas

Double-Angle
$$\sin 2\theta = 2\sin\theta\cos\theta$$ $$\cos 2\theta = \cos^2\theta - \sin^2\theta = 2\cos^2\theta - 1 = 1 - 2\sin^2\theta$$ $$\tan 2\theta = \frac{2\tan\theta}{1-\tan^2\theta}$$

3.4 — Half-Angle Formulas

Half-Angle (sign depends on quadrant of $\theta/2$)
$$\sin\frac{\theta}{2} = \pm\sqrt{\frac{1-\cos\theta}{2}} \qquad \cos\frac{\theta}{2} = \pm\sqrt{\frac{1+\cos\theta}{2}}$$

3.5 — Proving Identities

Strategy for Proving Identities
Work on one side only. Use algebra + identities to transform it into the other side. Start with the more complicated side. Useful tactics: convert everything to $\sin$/$\cos$; factor; multiply by conjugates; combine fractions.

Worked Example 3.2

Prove: $\dfrac{\sin\theta}{1-\cos\theta} - \dfrac{\sin\theta}{1+\cos\theta} = 2\cot\theta$

Work on the left side — combine fractions:

$$\text{LHS} = \frac{\sin\theta(1+\cos\theta) - \sin\theta(1-\cos\theta)}{(1-\cos\theta)(1+\cos\theta)} = \frac{2\sin\theta\cos\theta}{1-\cos^2\theta} = \frac{2\sin\theta\cos\theta}{\sin^2\theta} = \frac{2\cos\theta}{\sin\theta} = 2\cot\theta \; \checkmark$$

Practice Problems

Solutions:
Problem 1
Find the exact value of $\sin\!\left(\dfrac{7\pi}{12}\right)$.
Solution

Write $\dfrac{7\pi}{12} = \dfrac{\pi}{4} + \dfrac{\pi}{3}$:

$$\sin\!\left(\frac{\pi}{4}+\frac{\pi}{3}\right) = \sin\frac{\pi}{4}\cos\frac{\pi}{3} + \cos\frac{\pi}{4}\sin\frac{\pi}{3} = \frac{\sqrt{2}}{2}\cdot\frac{1}{2} + \frac{\sqrt{2}}{2}\cdot\frac{\sqrt{3}}{2} = \frac{\sqrt{2}+\sqrt{6}}{4}$$
Problem 2
If $\cos\theta = \dfrac{3}{5}$ and $0 < \theta < \dfrac{\pi}{2}$, find $\sin 2\theta$ and $\cos 2\theta$.
Solution

$\sin\theta = \dfrac{4}{5}$ (positive in Q1).

$$\sin 2\theta = 2\cdot\frac{4}{5}\cdot\frac{3}{5} = \frac{24}{25}$$ $$\cos 2\theta = \cos^2\theta - \sin^2\theta = \frac{9}{25} - \frac{16}{25} = -\frac{7}{25}$$
Problem 3
Prove: $(\sin\theta + \cos\theta)^2 = 1 + \sin 2\theta$
Solution
$$\text{LHS} = \sin^2\theta + 2\sin\theta\cos\theta + \cos^2\theta = (\sin^2\theta+\cos^2\theta) + 2\sin\theta\cos\theta = 1 + \sin 2\theta \; \checkmark$$
